# Digital Kroft Portfolio

Welcome to the Digital Kroft Portfolio! This project is built using [Next.js](https://nextjs.org/) and [Framer Motion](https://www.framer.com/motion/) for smooth animations and a premium aesthetic.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Copy the example environment file and fill in your Resend API key and contact email.
   ```bash
   cp .env.local.example .env.local
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Modern, sleek, and premium design
- Fully responsive layout
- Working Contact Form using Resend
- Smooth scroll and reveal animations via Framer Motion

## Deployment

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new). Check out the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
